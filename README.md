## Projects

## Governance Approach

Both projects followed a structured governance methodology:

1. **Risk Identification** — mapped AI-specific failure modes across the full pipeline
2. **Control Design** — designed mitigations proportionate to risk severity
3. **Validation** — tested controls systematically with documented test cases and acceptance criteria
4. **Documentation** — produced audit-ready artefacts including risk registers, validation reports, and governance policies
5. **Remediation Tracking** — logged defects with severity ratings, owners, and resolution actions
